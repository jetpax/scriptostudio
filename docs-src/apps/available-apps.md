# Available Apps

These Apps are on ScriptoHub. Install them from the **+** beside **Apps** in the menu. See [Apps](index.md).

| App | ID | What it does |
|---|---|---|
| **CAN Monitor** | `can-monitor` | Watches a CAN bus live: frame rates, bus load, anything lost, and the busiest identifiers. |
| **CCS** | `ccs` | CCS/NACS DC fast charging: an EVSE emulator for contactor closure. |
| **DBE** | `dbe` | Dala The Great's Battery Emulator: a CAN-to-RS485 bridge for battery management systems. Bridges EV battery packs to solar inverters. |
| **DTC** | `dtc` | Reads, displays and clears diagnostic trouble codes from vehicle ECUs via UDS/OBD2. Includes 12,000+ code descriptions. |
| **GVRET** | `gvret` | A GVRET implementation for MicroPython. Lets SavvyCAN connect over TCP/IP for vehicle network analysis. |
| **OpenInverter** | `openinverter` | Configures OpenInverter motor controllers: parameters, CAN message mapping, spot values and real-time signal plots. |
| **OVMS** | `ovms` | Pushes vehicle metrics to an OVMS v2 server for remote monitoring. |
| **PFC** | `pfc` | Prefrontal Cortex: an agent orchestrator for ESP32. Chat with an LLM that can read and write files and run Python on the board. |
| **SmartGBW** | `smart-gbw` | A grind-by-weight coffee grinder controller with a predictive grinding algorithm. The touch UI runs on the board (ESP32-S3 AMOLED), and a JavaScript view charts past sessions. |

The list changes as developers publish. [Browse apps](https://scriptohub.ai/extensions) shows what's there.
