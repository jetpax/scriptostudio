# About

**Settings > About** shows what the connected board is. Without a board connected, it says to connect one.

| Field | Meaning |
|-------|---------|
| **Board** | The board's name, from its manifest. |
| **Hardware** | What the board has on it, from its manifest. |
| **botIQ** | The botIQ release on the board. |
| **Firmware** | The firmware build. |
| **MicroPython** | The MicroPython version the firmware is built on. |
| **Address** | The board's name on your network. |

See [Board Configurations](../device-setup/board-configurations.md).

About also offers what Studio can do next: a newer Studio to reload into, installing Studio as an app, or a newer botIQ for the board.

## Status bar

The bar at the bottom of Studio shows live readings:

| Indicator | Meaning |
|-----------|---------|
| **RAM** | Memory in use. |
| **TEMP** | Chip temperature. |
| **UPTIME** | Time since boot. |
| **RSSI** | WiFi signal strength. |
