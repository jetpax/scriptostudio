# ScriptO Studio

Tell your board what to do. An agent writes the MicroPython, tries it on your real hardware and leaves it running on the board, while you watch and can stop it.

This repository holds the site at [scriptostudio.com](https://scriptostudio.com), the built app, the board manifests, the scripts that run on a board, and `ss-relay`. Studio's source is in [scripto-studio](https://github.com/jetpax/scripto-studio), and the firmware is in [pyDirect](https://github.com/jetpax/pyDirect).

## Install

Open [scriptostudio.com/app](https://scriptostudio.com/app/) in Chrome or Edge, plug in a board, and click **Set up a new board**. There's nothing else to install. See [Getting Started](https://scriptostudio.com/docs/getting-started/).
