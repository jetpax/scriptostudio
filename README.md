# ScriptO Studio - Natural Language programming for Robots.

Tell your board what to do. An agent writes the code, tries it on your real hardware and leaves it running on the board, while you watch and can stop it.

Scripto Studio is engineered for agent-first development. Studio and any board it runs with speak [MCP](https://modelcontextprotocol.io) (the Model Context Protocol), the same protocol an agent such as Claude Code uses, so Studio, agents and apps all reach a board the same way.

This repository holds the site at [scriptostudio.com](https://scriptostudio.com), its docs and the built app. What runs on the board is [botIQ](https://github.com/jetpax/botiq), running on MicroPython with [pyDirect](https://github.com/jetpax/pyDirect); Studio installs both from [ScriptoHub](https://scriptohub.ai).

## Install

Open [scriptostudio.com/app](https://scriptostudio.com/app/) plug in a board, and click **Set up a new board**. There's nothing else to install. See [Getting Started](https://scriptostudio.com/docs/getting-started/).
